← Back to the flasher. Diagnostic page: checks that this laptop can talk to the board over USB. It only reads information. Nothing on the board is changed.

This browser can't access USB devices.

Open this page in Microsoft Edge or Google Chrome on a Windows, Mac or Linux computer (not a phone).กรุณาเปิดหน้านี้ด้วย Microsoft Edge หรือ Google Chrome บนคอมพิวเตอร์

  1. Plug the display board's USB cable into this laptop.เสียบสาย USB ของบอร์ดจอเข้ากับคอมพิวเตอร์
  2. Click Check USB device and pick the board in the list.กด Check USB device แล้วเลือกบอร์ดจากรายการ
  3. If the board isn't in the list, also try Check serial port.ถ้าไม่เจอบอร์ดในรายการ ให้ลองกด Check serial port
  4. Click Copy report and send it to the DOM team.กด Copy report แล้วส่งให้ทีม DOM
